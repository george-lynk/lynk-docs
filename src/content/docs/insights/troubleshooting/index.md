*Περιγράφει την τρέχουσα έκδοση της εφαρμογής.*

Βρείτε το πρόβλημα που βλέπετε:

| Τι βλέπετε | Πού θα βρείτε τη λύση |
|---|---|
| Μια παραγγελία δείχνει **Push failed** στο **Αρχείο Παραγγελιών** του Softone | [Σφάλματα αποστολής στο Softone](/insights/troubleshooting/softone-document-errors/) |
| Οι νέες παραγγελίες ενός καναλιού δεν εμφανίζονται στο Lynk | [Οι παραγγελίες δεν εμφανίζονται](/insights/troubleshooting/orders-not-arriving/) |
| Δεν μπορείτε να συνδεθείτε ή δεν βλέπετε μια σελίδα | [Σύνδεση και πρόσβαση](/insights/troubleshooting/sign-in-and-access/) |
| Μια παραγγελία δεν δημιουργήθηκε στο Shopify | [Προώθηση παραγγελιών](/insights/channels/order-relay/) |
| Οι προμήθειες του Shopflix δεν ενημερώνονται | [Shopflix](/insights/channels/shopflix/) |
