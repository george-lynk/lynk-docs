*Περιγράφει την τρέχουσα έκδοση της εφαρμογής.*

Η σελίδα **Παραγγελίες** δείχνει όλες τις παραγγελίες του διαστήματος που επιλέγετε στην πάνω γραμμή, ομαδοποιημένες ανά ημέρα. Οι ενδείξεις κατάστασης εμφανίζονται ως εικονίδια· περάστε τον δείκτη του ποντικιού από πάνω τους για να δείτε το όνομά τους (προς το παρόν στα αγγλικά).

## Στήλες

| Στήλη | Τι δείχνει |
|---|---|
| **Κωδικός** | Ο κωδικός της παραγγελίας και το κανάλι. Η ένδειξη **FBS** σημαίνει παραγγελία Fulfilled by Skroutz |
| **Προϊόν** | Το προϊόν ή πόσα προϊόντα έχει η παραγγελία. Πατήστε τη γραμμή για να δείτε κάθε προϊόν |
| **Ποσ.** | Τα τεμάχια |
| **Έσοδα** | Η αξία της παραγγελίας |
| **Προμήθεια** | Η προμήθεια του καναλιού, και ως ποσοστό των εσόδων |
| **Καθαρό** | Ό,τι σας μένει μετά την προμήθεια |
| **Περιθώριο** | Το περιθώριο κέρδους, αν υπάρχει κόστος για όλα τα προϊόντα |
| **Κατάσταση** (πρώτη) | Η κατάσταση της παραγγελίας στο κανάλι. Δείτε τον πίνακα παρακάτω |
| **Κατάσταση** (δεύτερη) | Αν η παραγγελία είναι κερδοφόρα. Δείτε τον πίνακα παρακάτω |
| Εικονίδιο Shopify / Relay | Αν η παραγγελία στάλθηκε στο Shopify ή στο Relay. Εμφανίζεται όταν έχετε συνδέσει Shopify ή Relay |
| Εικονίδιο Softone | Η κατάσταση αποστολής στο Softone. Εμφανίζεται όταν έχετε συνδέσει Softone |

## Κατάσταση στο κανάλι

| Ένδειξη | Τι σημαίνει | Μετρά στα έσοδα |
|---|---|---|
| **Open** / **New** | Νέα παραγγελία που δεν έχει γίνει ακόμη αποδεκτή ή πληρωθεί | Ναι |
| **Accepted** | Η παραγγελία έγινε αποδεκτή (Skroutz, Shopflix) ή πληρώθηκε (Shopify) | Ναι |
| **Dispatched** | Η παραγγελία στάλθηκε. Στο Shopify: εκτελέστηκε μερικώς | Ναι |
| **Delivered** | Η παραγγελία παραδόθηκε. Στο Shopify: εκτελέστηκε πλήρως (fulfilled) | Ναι |
| **Partially Delivered** | Παραδόθηκε μέρος της παραγγελίας | Ναι |
| **Failed** | Το κανάλι σημείωσε την παραγγελία ως αποτυχημένη | Ναι |
| **Cancelled** | Η παραγγελία ακυρώθηκε | Όχι |
| **Rejected** | Η παραγγελία απορρίφθηκε | Όχι |
| **Expired** | Η παραγγελία έληξε χωρίς να γίνει αποδεκτή | Όχι |
| **For Return** | Η παραγγελία είναι σε διαδικασία επιστροφής | Όχι |
| **Returned** | Η παραγγελία επιστράφηκε. Στο Shopify: έγινε πλήρης επιστροφή χρημάτων | Όχι |
| **Partially Returned** | Επιστράφηκε μέρος της παραγγελίας. Στο Shopify: έγινε μερική επιστροφή χρημάτων | Όχι |

Οι παραγγελίες που δεν μετρούν στα έσοδα είναι οι **εξαιρεμένες παραγγελίες**. Τις βλέπετε στις κάρτες **Εξαιρεμένες Παραγγελίες**, **Απώλεια Εσόδων** και **Μέση Εξαιρεμένη Παραγγελία** στο πάνω μέρος της σελίδας.

## Κερδοφορία

| Ένδειξη | Τι σημαίνει |
|---|---|
| **Κερδοφόρες** | Το περιθώριο είναι ίσο ή μεγαλύτερο από τον **Προτιμώμενο Στόχο Περιθωρίου** στις **Ρυθμίσεις** |
| **Χαμηλό Περιθώριο** | Το περιθώριο είναι μικρότερο από τον στόχο |
| **Χωρίς Κόστος** | Λείπει το κόστος για ένα ή περισσότερα προϊόντα, οπότε δεν υπολογίζεται περιθώριο. Δείτε [Κέρδη & κόστη](/insights/profit-costs/) |

## Αποστολή στο Softone

| Ένδειξη | Τι σημαίνει |
|---|---|
| Ρολόι | Σε αναμονή για αποστολή στο Softone |
| Περιστρεφόμενο εικονίδιο | Στέλνεται τώρα |
| Πράσινο σημάδι | Στάλθηκε στο Softone |
| Κόκκινο Χ | Η αποστολή απέτυχε. Δείτε [Αρχείο παραγγελιών Softone](/insights/softone/document-log/) |

## Υγεία εκπλήρωσης

| Ένδειξη | Ποσοστό παραγγελιών που δεν εξαιρέθηκαν |
|---|---|
| **Εξαιρετική** | 95% και πάνω |
| **Καλή** | 80% έως 95% |
| **Μέτρια** | 60% έως 80% |
| **Χρειάζεται Βελτίωση** | Κάτω από 60% |

## Φίλτρα και ενέργειες

| Στοιχείο | Τι κάνει |
|---|---|
| **Αναζήτηση παραγγελιών ή προϊόντων...** | Βρίσκει παραγγελίες με βάση τον κωδικό ή το προϊόν |
| **Όλα τα κανάλια** και ένα κουμπί ανά κανάλι | Δείχνει μόνο τις παραγγελίες ενός καναλιού. Εμφανίζεται όταν έχετε περισσότερα από ένα κανάλια |
| **Όλα**, **Κερδοφόρες**, **Χαμηλό Περιθώριο**, **Χωρίς Κόστος** | Φιλτράρει με βάση την κερδοφορία |
| **Sync states** | Ενημερώνει τις καταστάσεις των παραγγελιών από τις ενημερώσεις που έχουν ήδη φτάσει από τα κανάλια |
| **Εξαγωγή CSV** | Κατεβάζει τις παραγγελίες που βλέπετε σε αρχείο CSV |
