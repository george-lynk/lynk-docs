Σύνδεση των καναλιών πώλησης από τα οποία έρχονται οι παραγγελίες σας.

## Τι θα καλύπτει αυτή η ενότητα

- **Skroutz**: σύνδεση του καταστήματός σας στο Skroutz ώστε οι παραγγελίες να εμφανίζονται αυτόματα.
- **Shopflix**: σύνδεση του καταστήματός σας στο Shopflix ώστε οι παραγγελίες να εμφανίζονται αυτόματα.
- **Shopify**: σύνδεση του καταστήματός σας στο Shopify ώστε οι παραγγελίες να εμφανίζονται αυτόματα.
- **OpenCart**: σύνδεση του καταστήματός σας σε OpenCart ώστε οι παραγγελίες να εμφανίζονται αυτόματα.
- **Προώθηση παραγγελιών**: πώς οι παραγγελίες από τα κανάλια πώλησης προωθούνται αυτόματα στο ERP σας.

:::note
Η ενότητα ετοιμάζεται. Τα άρθρα θα δημοσιευτούν σύντομα.
:::
