*Περιγράφει τη νέα έκδοση της εφαρμογής, που έρχεται σύντομα.*

Συνδέστε τον λογαριασμό της επιχείρησής σας στην ACS ή στο BOX NOW με το Lynk Insights. Με τη σύνδεση, το Lynk θα δείχνει σε κάθε παραγγελία του e-shop σας:

- αν το δέμα είναι καθ' οδόν, στη θυρίδα, παραδόθηκε στον πελάτη ή επιστράφηκε, και πότε·
- αν ο παραλήπτης αρνήθηκε το δέμα ή δεν παραδόθηκε, με την αιτία που δίνει η courier·
- για την αντικαταβολή: αν εισπράχθηκε από τον πελάτη και αν σας αποδόθηκε.

Η σύνδεση γίνεται πρώτη. Η παρακολούθηση των αποστολών στις παραγγελίες έρχεται σε επόμενη έκδοση.

:::note[Μόνο οι παραγγελίες του e-shop σας]
Η παρακολούθηση αφορά τις παραγγελίες του e-shop σας (Shopify). Τις παραγγελίες του Skroutz και του Shopflix δεν τις παρακολουθεί: την παράδοσή τους τη δείχνει το ίδιο το marketplace, και την αντικαταβολή σας την αποδίδει το marketplace.
:::

## Τι διαβάζει το Lynk

Το Lynk **μόνο διαβάζει** από την courier. Δεν δημιουργεί, δεν εκτυπώνει και δεν ακυρώνει vouchers και δεν εκδίδει λίστες παραλαβής.

Από κάθε αποστολή κρατά τον αριθμό voucher, την κατάσταση με τις ώρες της, το κατάστημα ή τη θυρίδα, και τα ποσά της αντικαταβολής. Δεν κρατά ποτέ το όνομα, το τηλέφωνο, το email ή τη διεύθυνση του παραλήπτη.

## Τι χρειάζεστε από την courier

### ACS

Ζητήστε από την ACS πρόσβαση στα web services της. Θα σας δώσει:

| Στοιχείο | Τι είναι |
|---|---|
| API key | Το κλειδί πρόσβασης στα web services της ACS |
| Company ID και Company password | Τα στοιχεία της εταιρείας σας στην ACS |
| User ID και User password | Τα στοιχεία του χρήστη που θα χρησιμοποιεί το Lynk |

Ζητήστε το κλειδί να έχει δικαίωμα στις κλήσεις ανάγνωσης: παρακολούθηση αποστολής (σύνοψη και αναλυτικά), απόδοση αντικαταβολών, λίστες παραλαβής και αναζήτηση voucher με κλειδί αναφοράς.

:::tip[Αν ο λογαριασμός σας στην ACS έχει κλείδωμα IP]
Η ACS δέχεται τότε κλήσεις μόνο από συγκεκριμένες διευθύνσεις. Ζητήστε από την υποστήριξη του Lynk τις διευθύνσεις του Lynk και δώστε τες στην ACS να τις προσθέσει.
:::

### BOX NOW

Ζητήστε από την υποστήριξη του BOX NOW κλειδιά για το Partner API. Θα σας δώσει:

| Στοιχείο | Τι είναι |
|---|---|
| Client ID και Client secret | Τα στοιχεία σύνδεσης του λογαριασμού σας |
| API URL | Η διεύθυνση του API: για δοκιμές (stage) ή για τον κανονικό λογαριασμό (production) |
| Partner ID | Μόνο αν ο λογαριασμός σας διαχειρίζεται περισσότερους από έναν partners |

## Σύνδεση

1. Από το μενού, ανοίξτε **Συνδέσεις** και επιλέξτε **ACS** ή **BOX NOW**.
2. Συμπληρώστε τα στοιχεία που σας έδωσε η courier και αποθηκεύστε.
3. Πατήστε **Δοκιμή σύνδεσης**. Το Lynk κάνει μία ανάγνωση στην courier και σας δείχνει το αποτέλεσμα σε λίγα δευτερόλεπτα.

Οι κωδικοί και τα κλειδιά αποθηκεύονται κρυπτογραφημένα και δεν εμφανίζονται ξανά. Στη φόρμα βλέπετε μόνο ότι είναι αποθηκευμένα. Για να αλλάξετε ένα στοιχείο, γράψτε το καινούριο· τα πεδία που αφήνετε κενά κρατούν την αποθηκευμένη τιμή.

## Αν η δοκιμή αποτύχει

| Μήνυμα | Τι σημαίνει | Τι κάνετε |
|---|---|---|
| Τα στοιχεία δεν έγιναν δεκτά | Το BOX NOW δεν δέχτηκε το Client ID ή το Client secret | Ελέγξτε τα, και ότι ταιριάζουν με το API URL (stage ή production) |
| Ο λογαριασμός είναι απενεργοποιημένος | Το BOX NOW έχει απενεργοποιήσει τον λογαριασμό | Επικοινωνήστε με το BOX NOW |
| Λάθος κλειδί ή διεύθυνση εκτός λίστας | Η ACS δεν δέχτηκε το API key, ή ο λογαριασμός έχει κλείδωμα IP και το Lynk δεν είναι στη λίστα | Ελέγξτε το API key· ρωτήστε την ACS αν υπάρχει κλείδωμα IP |
| Η courier απάντησε με σφάλμα | Η ACS δεν δέχτηκε τα στοιχεία εταιρείας ή χρήστη, ή το κλειδί δεν έχει δικαίωμα στην κλήση | Ελέγξτε τα στοιχεία· ζητήστε από την ACS τα δικαιώματα της παραπάνω λίστας |
| Η courier δεν απαντά | Η courier δεν απάντησε εγκαίρως | Δοκιμάστε ξανά σε λίγα λεπτά |

## Ειδοποίηση για καθυστερημένη απόδοση αντικαταβολής

Στη σελίδα της courier ορίζετε μετά από πόσες εργάσιμες ημέρες από την είσπραξη θέλετε ειδοποίηση, αν δεν σας έχει αποδοθεί η αντικαταβολή (από 1 έως 30, προεπιλογή 7).

## Αποσύνδεση

Στη σελίδα της courier πατήστε **Αποσύνδεση** και επιβεβαιώστε. Τα στοιχεία σύνδεσης διαγράφονται αμέσως και η παρακολούθηση σταματά. Το ιστορικό των αποστολών που έχει ήδη το Lynk μένει στις παραγγελίες σας.
