*Περιγράφει την τρέχουσα έκδοση της εφαρμογής.*

Οι όροι που χρησιμοποιούμε σε όλη την τεκμηρίωση, με την αντίστοιχη απόδοση στα αγγλικά.

| Όρος | Τι σημαίνει | Στα αγγλικά |
|---|---|---|
| **ΑΦΜ** | Ο αριθμός φορολογικού μητρώου ενός πελάτη ή του καταστήματός σας. Σε κάποιες οθόνες της εφαρμογής εμφανίζεται ως Α.Φ.Μ. | VAT number (ΑΦΜ) |
| **ΔΟΥ** | Η εφορία στην οποία ανήκει ένας πελάτης-επιχείρηση | tax office (ΔΟΥ) |
| **Απόδειξη** | Το παραστατικό λιανικής για πελάτη ιδιώτη (B2C) | receipt |
| **Τιμολόγιο** | Το παραστατικό για πελάτη επιχείρηση (B2B) | invoice |
| **Παραστατικό** | Κάθε έγγραφο πώλησης στο Softone | document |
| **Παραστατικό παραγγελίας** | Το παραστατικό που δημιουργεί το Lynk στο Softone για κάθε παραγγελία. Δεν είναι απόδειξη ή τιμολόγιο | order document |
| **Τελικό παραστατικό** | Η απόδειξη ή το τιμολόγιο που εκδίδετε εσείς ή ο λογιστής σας στο Softone από το παραστατικό παραγγελίας | final document |
| **Σειρά** | Η σειρά αρίθμησης παραστατικών στο Softone, για παράδειγμα μία για λιανική και μία για χονδρική | series |
| **Λιανική (B2C)** | Πώληση σε ιδιώτη, για απόδειξη | retail (B2C) |
| **Χονδρική (B2B)** | Πώληση σε επιχείρηση, για τιμολόγιο | wholesale (B2B) |
| **Κανάλι** | Το σημείο όπου πουλάτε: Shopify, Skroutz, Shopflix ή OpenCart | channel |
| **Marketplace** | Πλατφόρμα όπου πουλάτε μαζί με άλλους πωλητές, όπως το Skroutz και το Shopflix | marketplace |
| **Προμήθεια** | Το ποσό που κρατά το κανάλι για κάθε παραγγελία | commission |
| **Καθαρό** | Ό,τι σας μένει από μια παραγγελία μετά την προμήθεια | net payout |
| **Περιθώριο** | Το κέρδος ως ποσοστό των εσόδων | margin |
| **Καθαρό κέρδος** | Ό,τι μένει μετά την προμήθεια και το κόστος των προϊόντων | net profit |
| **Εξαιρεμένη παραγγελία** | Παραγγελία που ακυρώθηκε, απορρίφθηκε, έληξε ή επιστράφηκε. Δεν μετρά στα έσοδα | excluded order |
| **Συγχρονισμός** | Η μεταφορά δεδομένων από ένα σύστημα στο Lynk, όπως οι παραγγελίες ή το κόστος | sync |
| **Αποστολή** | Η δημιουργία μιας παραγγελίας ή ενός παραστατικού σε άλλο σύστημα, όπως στο Softone ή στο Shopify | push / send |
| **Προώθηση (relay)** | Η αυτόματη δημιουργία των παραγγελιών των marketplaces στο Shopify ή στο OpenCart | relay |
| **Webhook** | Ειδοποίηση που στέλνει ένα κανάλι στο Lynk τη στιγμή που γίνεται μια παραγγελία ή αλλάζει | webhook |
| **Περιβάλλον Demo / Παραγωγής** | Η δοκιμαστική και η κανονική εγκατάσταση του Softone | Demo / Live environment |
| **Κάτοχος λογαριασμού** | Ο χρήστης που δημιούργησε τον λογαριασμό. Μόνο αυτός διαχειρίζεται την ομάδα | account owner |
| **Μέλος ομάδας** | Χρήστης που προσκάλεσε ο κάτοχος, με πρόσβαση μόνο στις σελίδες που του επιτρέπονται | team member |
| **FBS** | Fulfilled by Skroutz: παραγγελίες που αποστέλλει το Skroutz από τη δική του αποθήκη | FBS |
