# Lynk docs

Lynk documentation, published at https://docs.lynk.gr

One hub for every Lynk product, in Greek (default) and English. Built with
[Starlight](https://starlight.astro.build) and deployed to GitHub Pages on every
merge to `main`.

```sh
npm ci
npm run dev
```

Read [CONTRIBUTING.md](CONTRIBUTING.md) before writing or editing a page.
